Guides take one outcome from an empty starting point to working, verified code. Each one lists what you will build
and its prerequisites, then walks through numbered steps with complete files, every import shown and every file
named by its path. Each ends with a way to check that it works, the failures you are most likely to hit, and where
to go next.

Use a guide when you know what you want to build. To learn how a feature works, or to look up every option of an
API, start from [Concepts](/docs/concepts), the feature pages, or the [Reference](/docs/reference) instead; guides
link to them wherever a step relies on them.
